🔍 About Monolith Matrix

100% browser-standalone. This is a single self-contained HTML file: all styles, scripts and the full …-tool database are embedded. Open it from disk, double-click it, drop it in a shared drive, or serve it from any static host — it works with zero internet access (only the external tool links themselves need the network).

Contents. The directory is organized as the Monolith Matrix framework — … categories spanning social media, people & identity search, domain/IP/DNS, dorks, darknet, data dumps, public records, police/LE databases, government records, finance, cryptocurrency, maritime, flight tracking and more. The dataset was pulled directly from the live page (updated …); an ARCHIVE 2022 category preserves tools the author later removed, and links the maintainer flagged as returning HTTP 404 carry a ⚠ dead? badge.

Run tools in the browser. The directory links are live web tools and databases (CyberChef, Truecaller, HaveIBeenPwned…). Click the tool title or ▶ Run to open the external tool as a top-level page. This avoids iframe/CSP/X-Frame-Options problems in ToolBridge. Open ↗ uses the same external navigation path. The 🌐 Proxy start command uses python on Windows and python3 on macOS & Linux — the name each OS’s standard install provides — with the “Save as .py” route as an alternative.

Health-checked — usable only. Dataset cleanup updated on 2026-09-09. Obsolete entries and known dead domains are removed; renamed services are pointed to their current official domains. The ARCHIVE 2022 category keeps only the 5 tools from the old mirror that still work. Tor-only (`.onion`) links and bot-protected sites were left in — they can't be verified from a normal network.

Keeping it fresh — 100% in-browser. Hit the 🔄 Sync button in the header to import a JSON snapshot (this app's dataset export, or any plain category array), export the current dataset, or reset to the built-in snapshot. All data stays local in your browser — the app never fetches anything on its own.

Automation / ToolBridge. A tiny global API is exposed for tool bridges and browser automation. From the DevTools console or any bridge script:

MONOLITH.version          // "3.2.0"
MONOLITH.updated          // dataset date
MONOLITH.count            // tools (live-updating getter)
MONOLITH.dead             // dead-flagged links
MONOLITH.categories       // ["THROWAWAY CONTACT", …]
MONOLITH.search("email")  // → [{t,u,d,cat,dead,archive}, …]
MONOLITH.byCategory("EMAIL") // all tools in a category
MONOLITH.random()         // one random tool
MONOLITH.stats()          // counts per category
MONOLITH.importData(json) // apply a JSON snapshot
MONOLITH.resetData()      // restore built-in dataset
MONOLITH.dataset()        // current {updated, categories}
MONOLITH.notes.list()     // saved notes (array)
MONOLITH.notes.add(title, body)

Privacy — Publish is OFF. No telemetry, analytics or tracking of any kind; zero network at boot; favorites/notes/dataset stay in your browser. External tools open only when you click them, and the 🛡 Publish button in the header gives you a hard-offline lock that blocks all outbound access. This local file never contacts any analytics or tracking service.

Keyboard shortcuts. / or Ctrl/⌘+K → search · Esc → clear · R → random tool.

Freshness. Built-in dataset curated/cleaned on 2026-09-09: dead links removed, and modern OSINT tools (OSINT Industries, Blackbird, URLScan, InVID, Overpass Turbo, Sentinel Hub, AbuseIPDB, and many more) added across every category. Add or edit tools at any time via Sync → Import JSON.
